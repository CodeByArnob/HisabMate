Architecture & Technical Stack

Built from the ground up with modern Android engineering standards:

  • ✓ UI Layer: 100% Jetpack Compose with Material 3 & centralized HisabTheme Light/Dark semantic tokens.
  • ✓ State Management: Unidirectional MVVM via HisabViewModel & lifecycle-aware StateFlow pipelines.
  • ✓ Persistence: AndroidX Room SQLite v5 with 10 relational entities & reactive Kotlin Flow DAOs.
  • ✓ Verification: Automated Robolectric JVM unit & Compose UI test suite with Native Graphics screenshot validation.

Frequently Asked Questions

Everything you need to know about privacy, multi-currency accounting, and building HisabMate.

Does HisabMate send any financial data to external servers?

No. HisabMate does not even request the Android INTERNET permission. All accounts, transactions, budgets, exchange rates, and reminders are stored strictly on-device in Room SQLite.

How does multi-currency conversion work when offline?

HisabMate ships with verified baseline exchange rates for 14 major ISO 4217 currencies anchored to BDT and allows you to customize any exchange rate manually in the Currencies & FX Rates screen. Changing your base currency dynamically recalculates all dashboard totals while keeping every transaction's original currency intact.

How can I back up or migrate my financial records to a new phone?

Open Profile & Settings → Data Portability to export a complete JSON backup or CSV spreadsheet of your transactions, which can be restored on any device running HisabMate.
