Documentation & Trust

Frequently Asked Questions

Everything you need to know about privacy, multi-currency accounting, release verification, and building HisabMate.

Does HisabMate send any financial data to external servers?+

No. HisabMate does not even request the Android INTERNET permission. All accounts, transactions, budgets, exchange rates, and reminders are stored strictly on-device in Room SQLite v6.

Where can I download the compiled Android APK and App Bundle (AAB)?+

You can download HisabMate-v1.0.2-release.apk, HisabMate-v1.0.2-release.aab, and SHA256SUMS.txt directly from the GitHub Release v1.0.2 page or via the download buttons at the top of this website.

How does multi-currency conversion work when offline?+

HisabMate ships with verified baseline exchange rates for 14 major ISO 4217 currencies anchored to BDT and allows you to customize any exchange rate manually in the Currencies & FX Rates screen. Changing your base currency dynamically recalculates all dashboard totals while keeping every transaction's original currency intact.

How can I back up or migrate my financial records to a new phone?+

Open Profile & Settings → Data Portability to export a complete JSON backup or CSV spreadsheet of your transactions, which can be restored on any device running HisabMate.
