# HisabMate v1.0.6

This release includes the v1.0.6 application updates:

- Responsive UI fixes for account cards, settings actions, FX headings and analytics legends.
- Improved category label contrast and dashboard surface depth.
- Refined single-page A4 financial statement layout with adaptive text fitting and category allocation summary.
- Added native transaction activity notifications and Notification Center receipts after successful expense, income, transfer and edit operations.
- Refined dashboard category cards, shared card geometry, elevation, navigation dock and cross-screen surface hierarchy.
- Website and README refreshed for the v1.0.6 release.
